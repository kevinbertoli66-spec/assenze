ITS ASSENZE - PWA

Contatore delle ore di assenza ITS, massimo 200 ore.

FILE:
- index.html       interfaccia
- style.css        grafica
- app.js           logica e salvataggio
- manifest.json    configurazione PWA
- service-worker.js funzionamento offline
- icon-192.png     icona
- icon-512.png     icona

UTILIZZO:
Aprire index.html tramite un server web/hosting.
Per installarla su iPhone:
Safari -> Condividi -> Aggiungi alla schermata Home.

NOTA:
Per avere installazione PWA e funzionamento offline affidabile su iPhone,
il sito deve essere servito tramite HTTPS (ad esempio GitHub Pages, Netlify
o un altro hosting HTTPS). Aprire il file direttamente dal PC può bastare
per provare l'interfaccia, ma non per tutte le funzioni PWA.
